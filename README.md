# fix_retouch

RUNWAY / SwitchX 用の動画レタッチ補助アプリ。

## 目的

動画から任意のフレームを選び、対象領域を指定して画像AIで修正し、元解像度のリファレンスPNGとサービス別のプロンプトを作ります。SwitchX用には編集範囲を全フレームへ追跡した白黒マスク動画を生成する構成です。

## 目標フロー
1. 動画を取り込み、修正対象フレームを選ぶ
2. 修正箇所をトリミングする
3. トリミング後の画像に赤い丸・線で修正範囲を示す
4. OpenAI画像編集APIで消去・変更
5. 元フレームの解像度で合成、元画像とパカパカ比較
6. 修正PNG、RUNWAY用プロンプト、SwitchX用プロンプト、SwitchX用マスク動画を出力
